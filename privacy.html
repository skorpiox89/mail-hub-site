隐私权政策

适用于「Junkdrawer 聚合邮箱」——一个自托管的多邮箱聚合工具。最后更新：2026-10-20。

1. 适用范围

本工具是由个人部署在自有服务器上的内部工具，仅供部署者本人及其明确授权的账号使用， 不向公众提供服务，也没有注册功能。本政策说明本工具如何处理通过 IMAP / OAuth 获取的邮箱数据。

2. 收集哪些数据

  • 邮箱连接凭据：OAuth 的 refresh token，或 IMAP 授权码。以 AES-256-GCM 加密后存储在部署者自己的数据库中，密钥不与数据库放在一起。
  • 邮件头信息：发件人、收件人、抄送、主题、发送时间、大小、摘要片段、已读与星标状态。用于在列表里展示邮件。
  • 邮件正文：不持久化。仅在用户点开某一封邮件时实时从邮箱服务器拉取，展示后即丢弃。

不收集：通讯录、日历、云盘、位置、设备信息、浏览记录，以及任何与邮箱收发无关的数据。

3. 数据存放在哪里

全部数据保存在部署者自己控制的服务器上（自建数据库）。 不经过、也不上传到任何第三方服务，本工具没有运营方服务器，不存在「数据回传」。

4. 数据如何被使用

  • 展示统一收件箱、搜索、查看正文；
  • 把用户主动发起的「标记已读 / 加星标 / 移动或删除」写回邮箱服务器；
  • 统计未读数、上次同步时间等界面信息。

除此之外不作任何用途：不做用户画像，不做广告投放，不做数据挖掘。

5. 数据共享与转让

不出售、不出租、不共享、不转让任何邮箱数据给第三方。 唯一的外部通信对象是邮箱服务商本身（Google、Microsoft、QQ、网易、中国移动、中国电信）， 且仅限于 IMAP 协议所需的读写操作。

6. Google API 服务用户数据政策

本工具对从 Google API 获取的信息的使用，遵循 Google API 服务用户数据政策， 包括其中的有限使用（Limited Use）要求：

  • 仅将 Gmail 数据用于提供本工具明确展示的邮件浏览与标记功能；
  • 不将 Gmail 数据传输给第三方，除非为提供功能所必需或法律要求；
  • 不将 Gmail 数据用于广告投放、出售，或用于训练通用人工智能 / 机器学习模型；
  • 不允许多人读取同一份 Gmail 数据，除非部署者明确授权；

7. 保存期限与删除

  • 邮件头索引：保留至用户在工具中删除该账号，或手动清理。
  • 凭据：删除账号时一并删除；也可随时在 Google 账号的 第三方应用授权页撤销授权，撤销后本工具立即失去访问能力。
  • 删除操作不可恢复，但不影响邮箱服务器上的原始邮件——本工具的删除只清除本地索引与状态记录。

8. 安全性

  • 与邮箱服务器之间全程 TLS 加密（IMAP 993 隐式 TLS）；
  • 凭据使用 AES-256-GCM 加密存储，密钥通过环境变量单独配置；
  • 工具本身不对外开放注册，仅部署者本机 / 局域网访问。

9. 政策变更

如本政策发生变更，将更新本页面顶部的「最后更新」日期。

10. 联系方式

与本工具的数据处理有关的任何问题，请通过 GitHub Issues 联系。
